# pyMLB Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a daily MLB prediction engine using ridge regression on 18 pitching/batting/environment features, producing spread and totals picks.

**Architecture:** `pyMLB/` mirrors `pyNFL/` — standalone model engine with ridge regression, thin wrappers for Kalman/store/calibration from shared `core/`, standalone self-tune reimplementation with MLB-specific weight keys. Daily pipeline: grade → fetch stats → fetch pitcher → injuries → odds → weather → kalman drift → project → save/report.

**Tech Stack:** Python 3, pybaseball, numpy, scipy, sklearn (RidgeCV), Open-Meteo API, ESPN API, FanDuel API, The Odds API

**Spec:** `docs/superpowers/specs/2026-03-30-pyMLB-design.md`

Build the 18-feature vector in `FEATURE_COLUMNS` order:

  - Project margin contributions
  - Center around league average score (~4.5 runs per team)
  - Apply Kalman adjustments

- Compute market edges: model spread vs market spread, model total vs market total
- Compute P(cover) via `norm.cdf()` with variance propagation
- Assign confidence tiers: elite if P >= probElite, high if P >= probHigh, else PASS
- Build pick strings (e.g., "New York Yankees -1.5")
